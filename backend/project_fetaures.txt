## 🎯 User Flows
- ### Clipper Flow:
    - Browse gigs → Filter by skills
    - View gig details → Check if open/bidding
    - If open: Start working → Submit work
    - If bidding: Submit proposal → Wait for acceptance → Work → Submit
    - Creator reviews → Approved → Payment released
    - Check earnings → Withdraw when threshold met
- ### Creator Flow:
    - Create gig → Set type (open/bidding)
    - Publish → Receive applications/submissions
    - If bidding: Review proposals → Accept best bid
    - If open: Monitor submissions → Review & approve
    - Release payment → Rate clipper
    - Post content → Enable clipping requests
    - Apply for brand deals
- ### Brand Flow:
    - Create UGC campaign → Set requirements & budget
    - Publish → Receive submissions from creators/clippers
    - Review content → Approve/reject with feedback
    - Download approved content → Release payment
    - Track campaign analytics
    - Browse creators → Direct collaboration invite
